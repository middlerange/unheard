## Customization Template

| Element | Example |
|---------|---------|
| `[MYTH]` | "Retention is about features" |
| `[REALITY]` | "Retention is about solving core jobs + proving value fast" |
| `[Reason 1]` | "Features feel like the obvious lever to pull" |
| `[Bad outcome 1]` | "Feature overload → longer onboarding → lower activation" |
| `[Good outcome 1]` | "Focused feature + fast activation → higher retention" |
| `[Data point]` | "Teams focusing on core action see 2-3x higher retention" |

## Platform Rules

- **LinkedIn:** Full myth + evidence + 3 misconceptions + case study (persuasive)
- **Twitter:** Punchy myth/reality + consequence (attention-grabbing)
- **Reddit:** "Did you believe this?" framing (conversational)

## Pre-Publish Checklist

- [ ] Myth is actually widespread (not a strawman)
- [ ] Reality is backed by data or strong logic
- [ ] Evidence is credible and specific
- [ ] Case study illustrates the consequence
- [ ] Tone is educational, not condescending

## Engagement Notes

- **LinkedIn Engagement:** VERY HIGH - Myth-busting = saves, shares, comments
- **Twitter Engagement:** HIGH - Reality checks get engagement from believers + supporters
- **Reddit Engagement:** VERY HIGH - r/webdev + communities love having their assumptions challenged
