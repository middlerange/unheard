## Platform Rules

- **LinkedIn:** Problem + 3 causes + 3 steps + impact (teach the concept)
- **Twitter:** Problem headline + 1 root cause + 3-step solution (scannable)
- **Reddit:** "Help me understand" tone (not "here's the answer")

## Pre-Publish Checklist

- [ ] Problem is specific (not generic)
- [ ] Root causes are credible (not obvious)
- [ ] Solutions are actionable (someone can apply today)
- [ ] Impact is measurable (percentage, not "better")
- [ ] Tone balances empathy with pragmatism

## Engagement Notes

- **LinkedIn Engagement:** VERY HIGH - PMs struggling with blocker will save/share
- **Twitter Engagement:** MEDIUM-HIGH - Practical solutions get engagement
- **Reddit Engagement:** VERY HIGH - Problem-solving is Reddit's default mode
