## Platform Rules

- **LinkedIn:** Full comparison matrix + 3 dimensions + recommendation matrix (comprehensive)
- **Twitter:** Quick comparison + differentiator (scannable)
- **Reddit:** "Is this accurate?" framing (conversational, invites fact-checking)

## Pre-Publish Checklist

- [ ] Comparison is fair (no strawmanning competitors)
- [ ] Data is accurate (if citing numbers, verify)
- [ ] Analysis is based on real product knowledge (or transparent about gaps)
- [ ] Userorbit advantage is real (not inflated or misleading)
- [ ] Tone is confident but not defensive

## Engagement Notes

- **LinkedIn Engagement:** VERY HIGH - Evaluators actively searching for comparison content
- **Twitter Engagement:** HIGH - Competitive takes generate discussion + quote-tweets
- **Reddit Engagement:** HIGH - r/webdev + r/SaaS communities debate comparisons actively
