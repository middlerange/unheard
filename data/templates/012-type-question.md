# Template: Question / Validation Post

**Type:** Question / Engagement  
**Platforms:** Twitter (primary), Reddit, LinkedIn  
**Tone:** Curious + Conversational  
**Best For:** Gathering intel, validating ideas, starting discussions  

## Twitter Version (Primary)

---

**[HOOK - Open the Question]**
[General observation or problem statement]

**[SPECIFIC QUESTION]**
Do you [SPECIFIC BEHAVIOR]? 

[Context: Why you're asking / What problem this relates to]

**[OPTIONS / ALTERNATIVES to Choose From]**
- [Option A: Common approach]
- [Option B: Different approach]
- [Option C: Uncommon approach]

Which one matches you?

**[FOLLOW-UP INSIGHT]**
If you're [OPTION A], you probably have [SPECIFIC PROBLEM].
If you're [OPTION B], you probably see [SPECIFIC ADVANTAGE].
If you're [OPTION C], you're probably [SPECIFIC PERSONA].

---

**[SETUP]**

## Customization Template

| Element | Example |
|---------|---------|
| `[TARGET AUDIENCE]` | "Product managers at B2B SaaS" |
| `[SPECIFIC SITUATION]` | "You see Week 1 churn spike in a new cohort" |
| `[SPECIFIC DECISION]` | "Track it: Do you measure it daily or weekly?" |
| `[Option A]` | "Daily (chasing noise, lots of variance)" |
| `[Option B]` | "Weekly (more stable signal, slower to react)" |
| `[Option C]` | "Both (daily for signals, weekly for decision-making)" |
| `[Context]` | "This impacts how fast you catch and fix retention issues" |

## Platform Rules

- **Twitter:** Fast, conversational, A/B/C options format (scannable, engaging)
- **LinkedIn:** Slightly longer context, why each option matters (educational + engaging)
- **Reddit:** "Genuine question" tone (r/webdev, r/ProductManagement communities)

## Pre-Publish Checklist

- [ ] Question is specific (not vague like "what's your process?")
- [ ] Options are real choices people actually make (not strawmen)
- [ ] Context explains why you're asking (not random survey)
- [ ] Tone is genuinely curious (not disguised pitch)
- [ ] You actually plan to respond to comments (or it feels like broadcast)

## Engagement Notes

- **Twitter Engagement:** VERY HIGH - Questions = replies, QTs, discussions
- **LinkedIn Engagement:** HIGH - Professional context-specific questions drive comments
- **Reddit Engagement:** VERY HIGH - Genuine questions get detailed responses, upvotes

## Pro Tips

- Ask after you've built credibility (question posts work better when you have audience)
- Respond to every comment (shows you're genuinely curious)
- Follow up with insights ("Most replies said Option B, here's why that makes sense...")
- Use question posts to inform future content (what people struggle with = topic ideas)
