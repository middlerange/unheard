## LinkedIn Version

---

**[HEADLINE]**
The Churn Prediction Model: Know who's leaving before they leave

**[HOOK]**
Retention is reactive: You see churn in the data after it happens.

Churn prediction is proactive: You see it coming weeks before users leave.

The difference? 3 behavioral signals, measured together.

**[FRAMEWORK - The 3 Signals]**

**Signal 1: Feature Engagement Drop**
- User was active in core feature
- Usage dropped 40% or more (vs. their baseline)
- Happened in last 7 days

**Signal 2: Session Frequency Decline**
- User was logging in 3x/week
- Now logging in <1x/week
- Trend is accelerating (getting worse each week)

**Signal 3: Time-to-Action Increase**
- When user logs in, they take action in minutes
- Now they log in, browse, then leave
- Time between login and core action increased 50%

**[THE MODEL]**

If user exhibits all 3 signals = 80% churn risk in 14 days

Action: Proactive outreach (not "we miss you" but "here's what you're missing")
