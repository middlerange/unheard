**[HEADLINE]**
The best products don't just work—they activate. Here's how we measure it.

**[HOOK]**
We call it **Activation Velocity**: How fast users move from "onboarded" to "performing."

Most products track activation as a checkbox ✓ (sent welcome email, completed tutorial). That's not activation—that's checkbox completion.

Real activation is behavioral:
- User found the core value prop
- User performed the core action
- User came back the next day

**[FRAMEWORKS]**
*The 3 Stages of Activation Velocity:*

[AWARENESS STAGE — user lands, sees value, doesn't bounce]

[ACTIVATION STAGE — user performs core action, experiences "aha moment"]

[RETENTION STAGE — user comes back, takes action again, becomes habitual]

**[THE INSIGHT]**
Companies obsessed with velocity ship:
- Faster onboarding (not tutorial overload)
- Clearer jobs-to-be-done (not feature dumps)
- Behavioral tracking (not guess-based activation)

Companies that don't? 90% churn by Week 1.
