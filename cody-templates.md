## DETAILED TEMPLATES BY POST TYPE

### TEMPLATE 1: PLATFORM-SPECIFIC TUTORIAL (HIGHEST ROI)

**Structure:**

1. **Hook/Title** - "how to [do X on Platform Y] with [Tool/Code]"
2. **Why It Matters** - 1-2 lines establishing value
3. **Step-by-Step Breakdown** - 3-5 specific, stacked statements
4. **Requirements/Tools Needed** - API keys, custom setup, code access
5. **Visual Proof** - Screenshot of output, video walkthrough, or result
6. **Call to Action** - "Show more" or embedded next step

**Template Text:**

```

[Why someone should care - problem statement or benefit]

first, go to [platform] and [specific action]

[next specific step with tool/API/code]

[final step or critical action]

[attached media showing result]

people want this because [outcome people get]
```

## WRITING PATTERNS TO REPLICATE

### Pattern 1: Specificity with Numbers/Timeframes

- "20 minutes" (sets expectations)
- "2 weeks ago" (specific timeline signal)
- "30 minutes" (deadline/achievability)
- Always include: specific count, timeframe, or metric

### Pattern 2: Stacked Short Sentences

- Each line is a digestible thought
- No long paragraphs
- Uses line breaks for scannability
- Mimics casual chat/Slack tone

### Pattern 3: Tool/Platform Name Dropping

- Not vague ("code automation") → specific ("Claude code," "Facebook ads API")
- Actual platform/tool names drive searchability
- Creates specificity

### Pattern 4: Observable Action Language

- "go to [platform]"
- "extract [data]"
- "create [thing]"
- "designate [setting]"
- Commands are actionable

### Pattern 5: Proof-First Approach

- Video/screenshot of actual output
- Shows before/after
- Demonstrates the method worked
- Builds credibility

### Pattern 6: The "Attached to" Connector

- "attached to an environment"
- "attached to [next step]"
- Bridges separate concepts
- Implies relationship/integration
